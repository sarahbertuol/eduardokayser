# Como publicar um artigo no blog

**Painel:** `https://SEU-DOMINIO/studio` — faça login com a conta Google convidada.

## Publicar um novo post (5 passos)

1. **Posts do blog → ✏️ (criar novo)**
2. Preencha **Título** e clique em **Generate** no campo *URL (slug)*
3. Escreva o **Resumo** (1–2 frases — aparece nos cards)
4. Envie a **Imagem de capa** e preencha o *Texto alternativo* (descreva a foto)
5. Escreva o **Texto do post**, escolha a(s) **Categoria(s)** e clique em **Publicar** (botão verde, canto inferior direito)

O artigo aparece no site em poucos segundos.

## Dicas do editor
- **Títulos dentro do texto:** selecione a linha → menu *Parágrafo* → *Título (H2)* ou *Subtítulo (H3)*
- **Link:** selecione o texto → ícone 🔗 → cole a URL
- **Imagem no meio do texto:** botão **+** (ou *Insert*) → *Imagem* → preencha o texto alternativo e, se quiser, a legenda
- **Citação de destaque:** selecione a linha → *Citação*

## Agendar um post
Coloque uma **Data de publicação** futura e publique. O post só aparece no site a partir dessa data.

## Editar ou despublicar
- **Editar:** abra o post, altere e clique em **Publicar** de novo
- **Tirar do ar:** menu **⋯** (ao lado de Publicar) → *Unpublish*
- **Rascunho:** tudo que não foi publicado fica salvo automaticamente como rascunho

## SEO (opcional)
Aba **SEO** do post: título e descrição para o Google e imagem para compartilhamento no LinkedIn/WhatsApp (1200×630). Se ficarem vazios, o site usa título, resumo e capa automaticamente.
